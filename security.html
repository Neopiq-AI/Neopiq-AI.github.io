Security

ChatAdmin makes real changes in Microsoft Entra, Microsoft 365, Microsoft Azure and Microsoft Power Platform. This is how it stays under your control.

Approval on every change available now

  • Reads run at once. Every change stops at an Approve / Reject card naming the area, the environment, every step and the checks it ran.
  • A person approves. Nothing is approved by software; an automated check may only reject.
  • Unanswered for five minutes, a card declines itself.
  • Each card is bound to its environment, which is read again at approval: if it changed, the approval is refused.
  • After each step the object is read back from Microsoft, and the result reports that state.

What it can and cannot do

It reads directory objects, licences, mailbox sizes and permissions, Teams and SharePoint membership, Azure resources and costs, and Power Platform environments. It changes only what a card shows. Today it acts through identities a Neopiq operator set up for one Microsoft tenant.

It never:

  • Read a message, a calendar or a file’s contents
  • Create a client secret or password, or read a secret out of a vault
  • Assign Global Administrator from chat, or grant Owner in Azure
  • Forward mail outside your organisation, or delete a mailbox, team, site or file
  • Touch Conditional Access, authentication methods, domains or tenant settings
  • Act between your turns: no schedule, no background job

Signing in

  • Your Microsoft work account, identity scopes only. ChatAdmin learns your name, sign-in name and tenant id, and shows them on every card. available now
  • No administrative access is requested; nothing in your tenant is read or changed. The sign-in token is verified once and discarded.
  • Neopiq’s own organisation gets the full product; anyone else sees the demonstration and can request a pilot.
  • In your own organisation: your own Microsoft rights, your own sign-in on every change, no Neopiq keys, nothing installed. in development

Data

  • Session transcripts (requests, answers, cards, decisions) are kept in Neopiq’s own Microsoft Azure storage, with secret-shaped values removed.
  • What ChatAdmin reads goes to the language model; anything that looks like a key or password is blanked first.
  • This website stores and sends nothing: no cookies, no tracking.

in development Deleting transcripts after 90 days, and everything of an organisation that leaves.

Neopiq holds no security certification: no SOC 2 report, no ISO 27001. Report a vulnerability to contact@neopiq.ai with a subject starting SECURITY.
