We build ChatAdmin, and we are specific about where it stops

Neopiq GmbH is a Swiss company. ChatAdmin administers Microsoft Azure, Microsoft Entra, Microsoft 365 and Microsoft Power Platform through a conversation, and stops before every change until a person approves it. It exists because the objection to a tool with administrative access is never capability — it is control.

The problem we set out to fix

Most organisations that run on Microsoft do not have a specialist for each admin centre. The joiner, the leaver, the shared mailbox and the “who has access to this” question all wait for the one person who knows where each setting lives, and the tools that promise to help are either read-only dashboards or chatbots that explain the documentation and leave the work to you.

What we do about it

The first thing built was not a capability but a brake: an Approve / Reject gate that every change has to pass, that nothing can skip, and that declines by itself if nobody answers within five minutes. The capabilities were added behind it afterwards, area by area, each with ceilings enforced in code rather than in a prompt. Then the result: after every change the object is read back, and ChatAdmin reports that state, never its intention.

What we hold ourselves to

A person decides what changes

Reads run freely. Every change is shown to a person first and does not happen unless it is approved. Silence counts as no. Nothing is approved by software.

Verified, or not claimed

Success is reported from what was read back, not from a request having been sent. A partial result says which steps ran. If we cannot show the working, we do not make the claim.

Present tense only for what exists

Every forward-looking statement on this site carries a label: in development, or planned. The trust page says what certifications we hold (none) and what Marketplace status we have (none yet).

Microsoft-native, independent

ChatAdmin acts inside Microsoft’s own identity and administration surfaces. Neopiq is an independent software vendor and is not affiliated with, endorsed by, or sponsored by Microsoft.

What is true about the product today

ChatAdmin runs in a Neopiq-operated environment on Microsoft Azure, connected by a Neopiq operator to one Microsoft tenant. It is not yet open for self-service; Microsoft sign-in for customers is in development, and a Microsoft Marketplace listing is planned. There are no customer references, statistics or testimonials on this site because there are none yet, and a plausible-looking fabrication would be a defect, not a placeholder.

Other work

Neopiq also publishes a free, browser-only Planning Data Auditor for Microsoft Dynamics 365 Supply Chain Management. It is not part of the ChatAdmin story and is kept reachable for the people who use it.
