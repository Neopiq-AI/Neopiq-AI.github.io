Pricing

Four plans, by what you manage and how you operate. Every plan is the same ChatAdmin: it inspects, proposes, waits for your approval, executes and verifies.

Which plan? Three questions.

  1. Do you manage customer tenants?

    • Yes → MSP · CHF 299 / month

  2. What do you manage?

    • Microsoft 365 and Microsoft Entra → Essential · CHF 49 / month
    • Microsoft 365, Microsoft Entra, Microsoft Azure and Microsoft Power Platform → Standard · CHF 99 / month

  3. Do you need endpoint administration, security operations or organisational governance?

    • Yes → Enterprise

Every plan

  • No deployment project. No Neopiq consulting required.
  • Connect your Microsoft tenant with one administrator consent and start: ChatAdmin reads with your own Microsoft rights. available now
  • No per-employee licensing.
  • No artificial execution credits: no question limits, no token limits, nothing metered that you have to watch.
  • A person approves every change. Changes are not open for customers yet; when they open, each one waits on your own Approve card.
  • Execution with verification: every result is read back from Microsoft - in Neopiq's own environment today, for customers when changes open.

Your Microsoft licences, roles and service prerequisites still apply: a plan never adds Microsoft rights, and ChatAdmin asks for the permissions a capability needs before it uses them.

Scope and operating model, not a feature ladder

Essential and the Standard plan differ in the Microsoft platforms ChatAdmin administers and in the number of operators, never in quality: the same execution, the same approval, the same verification, the same safety.

The Standard plan grows deeper: more actions inside Microsoft 365, Microsoft Entra, Microsoft Azure and Microsoft Power Platform. Enterprise grows wider: endpoint administration, security operations, organisational governance and enterprise integrations. Neither is decided by headcount, and a third person does not force a change of plan.

MSP is a different operating model, not a bigger plan: the same execution platform across your customers’ tenants, with the active tenant visible on every screen and every card.

Moving from Essential to the Standard plan, or on to Enterprise, is a change of plan, not a migration: your organisation and its history stay where they are. in development
